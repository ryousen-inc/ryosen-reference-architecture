# 稜線リファレンスアーキテクチャ

地方中小企業の熟練者が持つ暗黙知（五感の判断、目利き、人と文脈の記憶）を、AIエージェントを含む業務システムへ転換するための参照実装です。

製品ではなく「型」です。株式会社稜線はこの型の上で個社の仕組みを設計し、地域のITパートナーはこの型の上で運用・拡張します。型を公開するのは、中身を隠さないこと自体が、お客様と地域パートナーへの約束だからです。

現在のバージョン: **v0.3-draft**

## 設計の前提

このアーキテクチャの形は、熟練者の知が文書化で渡らない三つの理由から決まっています。

- **箱は渡るが、矢印は渡らない** — 手順や基準値は書けるが、その間の遷移の判断は書き写しでは移らない。だから記録の単位は結論ではなく、どの観測からどの判断へ移ったかとする
- **項の一覧では、作用を書けない** — 他の要素の見え方を変えるものは、値ではなく関係として記述する必要がある
- **一般化すると嘘になる** — 条件に深く縛られた判断ほど、一般化の過程で落ちる。だから一般化せず、妥当スコープごと保存する

詳細は [`docs/overview.md`](docs/overview.md) を参照してください。
